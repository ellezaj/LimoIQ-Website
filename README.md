# LIMO IQ Website

Next.js 14 (App Router) + TypeScript + Tailwind CSS starter for the LIMO IQ
website.

## Stack

- **Next.js 14** (App Router) — static generation, fast page loads, strong SEO defaults
- **TypeScript**
- **Tailwind CSS** — design tokens live in `tailwind.config.ts`
- **next/font** — self-hosted Google Fonts (Fraunces for display, Manrope for body), no layout shift

## Getting started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.


## Deployment

Designed for [Vercel](https://vercel.com): connect the repo, no extra config
needed. Environment variables (form endpoint, analytics keys, etc.) can be
added in the Vercel dashboard.
